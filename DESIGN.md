# DigUp Windows — product design

Product promise: **find anything on Windows by what it means—not only what it’s called.**

Make the desktop app feel like a precision instrument: one dominant search field, scope chips, result confidence, type filters, and a preview pane. Surface local-processing status and model availability without hiding limitations.

Icon prompt: `precision search lens cutting through layered files to reveal one glowing result, local semantic Windows file search, geometric flat vector, dark ink, cyan beam, strong silhouette, no text, transparent background`.

Diagram: filesystem watcher → exact index → OCR/media extraction → local embeddings → ranking → preview, with a local privacy boundary and exact-search fallback.
