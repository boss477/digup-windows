Find files by what they mean

Native Windows search across filenames, documents, OCR and optional local semantics.

Download the preview Build from source
Windows 10 and 11, x64. MIT licence.

Six stages, two of them optional

  1. Filesystem watcher

    Follows the folders you choose.

  2. Exact index

    Names and text, always on.

  3. OCR and media extraction

    Optional, for scans, audio and video.

  4. Local embeddings

    Optional, from a server you configure.

  5. Ranking

    Merges exact and semantic results.

  6. Preview and open

    PDFs at the page, media at the timestamp.

If the embedding server is unavailable, DigUp falls back to exact search.

It reads inside six formats

Text is extracted on your machine. OCR covers images and scanned pages.

  • TXT
  • Markdown
  • RST
  • PDF
  • DOCX
  • ODT

You draw the privacy boundary

Stays on your machine

Exact indexing and document extraction run locally.

Goes where you point it

Semantic and multimedia search send content to the provider you configure. Use a localhost endpoint to keep it local.

Install it per user

The preview is not code-signed, so SmartScreen may warn.

Read the full install notes
  1. Download the zip and check it against SHA256SUMS.txt.
  2. Run ./check-prerequisites.ps1 from the extracted folder.
  3. Run ./install.ps1. Uninstalling keeps your settings.
